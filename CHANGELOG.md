# Changelog

## 0.1.0-beta.1

First public beta of the maintained UDL study tutor.

- Handwritten BM25, exact cosine search, and reciprocal rank fusion over SQLite.
- Source-aware book/notebook extraction with stable provenance and local crops.
- Buildless browser interface, CLI, source inspector, and local math-review workflow.
- Direct Groq, Gemini, compatible-HTTP, and Ollama answer adapters.
- Optional semantic dependencies; lexical search works without a key or model weights.
- Atomic index updates, reusable vectors, immutable snapshots, and recovery tests.
- CI, source/licensing boundaries, real screenshots, and documented evaluation limits.

Known limits: broader reference retrieval is 75%; theory/figure recall needs improvement. The public release omits development mathematical transcriptions. A fresh corpus requires local math review. Corpus/index usability is distinct from full release validation.
